\# LocalServe



A hyperlocal services booking marketplace — find and book trusted local service providers (plumbers, electricians, cleaners, etc.) with real-time slot availability.



\## Status

🚧 In development — Semester 5 Capstone Project (Day 1 of 60)



\## Tech Stack

\- Backend: FastAPI (Python)

\- Frontend: React.js

\- Database: PostgreSQL

\- Auth: JWT
